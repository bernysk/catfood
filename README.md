# Krmivo pre mačky — dátové prieskumy

Osobné prieskumy krmiva pre mačky na slovenskom a českom trhu. Všetky hodnoty sú stiahnuté
zo stránok výrobcov a pri každom produkte je uložený pôvodný text etikety.

🌐 **[bernysk.github.io/catfood](https://bernysk.github.io/catfood/)** — rozcestník s interaktívnymi tabuľkami

| Prieskum | Priečinok | Stav |
|---|---|---|
| **Mokré krmivo (kapsičky)** — 151 produktov, 15 značiek, rámec A–E | [`mokre-krmivo/`](./mokre-krmivo/) · [tabuľka](https://bernysk.github.io/catfood/mokre-krmivo/) | v4.2, október 2026 |
| **Granule: gastrointestinálne veterinárne diéty** — porovnanie na 1000 kcal, bez známky | `granule/` | pripravuje sa |

Každý prieskum má vlastné surové dáta, skripty, dokument aj tabuľku, aby sa nepomiešali.
Spoločná je len [`literatura/`](./literatura/) — citované odborné práce.

```
README.md          tento prehľad
index.html         rozcestník (GitHub Pages)
mokre-krmivo/      prieskum kapsičiek — vlastný README, dáta, skripty, tabuľka
granule/           prieskum veterinárnych granúl (pripravuje sa)
literatura/        odborné práce s otvorenou licenciou + bibliografia
```
